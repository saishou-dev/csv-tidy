# csv-tidy

CSV の整形・重複チェック・表記ゆれの統一を、ドライラン付きで行う小さなツールです。

## 1. できること

お手元の CSV の「前後の空白」「全角と半角の混在」「電話番号の書き方のばらつき」をそろえ、重複している行を見つけます。

**実行する前に、どの行のどの列がどう変わるかを一覧でお見せします**（ドライラン）。確認いただいてから、別名のファイルに書き出します。

元のファイルは一切書き換えません。追加のインストールは不要で、Python 3.10 以上があれば動きます（標準ライブラリのみ）。

## 2. 使い方

### ① まず結果の一覧を見る（ファイルは書きません）

```
python tidy.py sample/input.csv --dry-run --key メールアドレス
```

### ② 確認できたら書き出す

```
python tidy.py sample/input.csv --key メールアドレス --out sample/output.csv --log sample/output.log.txt
```

### ③ ツール自体の動作確認（テスト）

```
python -m unittest discover -s tests -v
```

主なオプションは次のとおりです。

| オプション | 内容 |
|---|---|
| `--dry-run` | 変更予定の一覧だけを表示し、ファイルを書かない |
| `--out PATH` | 整形後の CSV を書き出す先（元ファイルと同じ名前は拒否します） |
| `--key 列名` | 重複を見る列（例: `--key メールアドレス`）。複数回指定できます |
| `--keep-key-duplicates` | `--key` の重複を一覧に出すだけで、出力からは落とさない |
| `--phone-col 列名` | 電話番号としてそろえる列（既定では列名から自動判定します） |
| `--encoding` | 文字コード（既定 `utf-8-sig`／Excel 由来の CSV は `cp932`） |
| `--log PATH` | 結果の一覧をテキストファイルにも保存する（納品時の作業ログになります） |
| `--force` | `--out` の既存ファイルを上書きする |

## 3. 出力例（ドライラン）

同梱の `sample/input.csv`（32 行の架空の顧客リスト）に対する実際の出力から抜粋したものです。

```
== 変更予定（行番号 / 列 / 変更前 → 変更後）==
     2 行 / 電話番号 : 「03-0000-0011」 → 「0300000011」
     3 行 / 会社名 : 「 ダミー電機 」 → 「ダミー電機」
     3 行 / メールアドレス : 「hanako@example.com 」 → 「hanako@example.com」
     4 行 / 顧客ID : 「Ｃ００３」 → 「C003」
     4 行 / メールアドレス : 「ｊｉｒｏ＠ｅｘａｍｐｌｅ．ｃｏｍ」 → 「jiro@example.com」
     4 行 / 電話番号 : 「０３－００００－００１３」 → 「0300000013」
     5 行 / 担当者名 : 「ﾘｮｳ ｻﾌﾞﾛｳ」 → 「リョウ サブロウ」
     7 行 / 電話番号 : 「(03) 0000 0016」 → 「0300000016」
    12 行 / 会社名 : 「サンプル食品　」 → 「サンプル食品」
    16 行 / 電話番号 : 「+81-90-0000-0024」 → 「+819000000024」
    （以下省略）

== 重複として落ちる行 ==
     9 行: 完全重複（3 行目と同一）
    10 行: メールアドレス の重複（2 行目と同じ「taro@example.com」）
    22 行: 完全重複（21 行目と同一）
    29 行: メールアドレス の重複（3 行目と同じ「hanako@example.com」）

== 空欄の件数（出力後）==
  担当者名: 1 件
  メールアドレス: 1 件
  電話番号: 1 件
  都道府県: 3 件
  備考: 12 件

== 集計 ==
  読み込み 32 行
  出力 28 行
  変更セル 46 個
  重複で除外 4 行
  電話番号として統一した列: 電話番号
  重複を見た列: メールアドレス

※ ドライランのため、ファイルは1つも書き込んでいません。
```

行番号は見出し行を 1 行目とした数え方で、Excel で開いたときの行番号と同じです。

整形後の内容は `sample/expected_output.csv` に入れてあり、テストで毎回突き合わせています。

## 4. 対応している整形の一覧

| # | 整形 | 例 |
|---|---|---|
| 1 | 前後の空白を取り除く（半角スペース・全角スペース・タブ・改行） | `「 ダミー電機 」` → `「ダミー電機」` |
| 2 | 全角の英数字を半角にする | `Ｃ００３` → `C003` |
| 3 | 全角の `＠ ． － ＿ ＋` を半角にする | `ｊｉｒｏ＠ｅｘａｍｐｌｅ．ｃｏｍ` → `jiro@example.com` |
| 4 | 半角カナを全角カナにする（濁点・半濁点は1文字にまとめる） | `ﾀﾞﾆｰ ｼﾞｭｳｲﾁ` → `ダニー ジュウイチ` |
| 5 | 電話番号をハイフンなしの数字にそろえる（空白・括弧・全角も対応） | `(03) 0000 0016` → `0300000016` |
| 6 | 国番号の先頭の `+` は残す | `+81-90-0000-0024` → `+819000000024` |
| 7 | 全列が一致する行（完全重複）を 1 行にまとめる | 9 行目を 3 行目と同一として除外 |
| 8 | 指定した列の重複を見つける（既定では除外・残すことも可能） | メールアドレスの重複 2 件 |
| 9 | 列ごとに空欄の件数を数える | 都道府県: 3 件 |

安全側に寄せている点は次のとおりです。

語の間の空白は残します（`テスト 太郎` はそのまま）。

日本語の文章で使う全角記号（`（ ） ／ ：` など）は半角に直しません。

電話番号の列に数字が1つも無い記入（例: `なし`）は書き換えず、そのまま残します。

空欄は推測で埋めません。件数を数えてご報告します。

## 5. お仕事の進め方

このツールと同じ3段階で進めます。

**① 要件を1ページにまとめてご確認いただきます。**
対象のファイル、そろえたい表記、重複を見る列、納品形式を箇条書きにして、着手前にお送りします。

**② ドライランの結果一覧をお見せします。**
「どの行のどの列がどう変わるか」と「重複として落ちる行」を全件お出しします。判断に迷う箇所は推測で埋めず、該当の行番号を添えてご相談します。

**③ 実行・検証して、成果物と作業ログを納品します。**
件数（読み込み・出力・変更セル・重複除外・空欄）を突き合わせてから納品します。元のファイルは変更せず、別名のファイルでお渡しします。
